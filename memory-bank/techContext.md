## Styling System

- **Tailwind CSS v4** with `@tailwindcss/postcss` PostCSS plugin
- CSS `@theme inline` block in `globals.css` defines semantic color tokens and font families
- All colors are hardcoded hex values in components (not Tailwind color scale classes like `gray-50`)

- No CSS modules, no styled-components, no CSS-in-JS
- Responsive breakpoints: mobile `640px`, tablet `1024px`, desktop `1100px+`
